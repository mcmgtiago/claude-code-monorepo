## 🎁 Recomendação de Projeto (4 Nichos)

Crie **1 site-base por nicho**:

```
sites/
├── contadores/              # Base: Consora (tema Accounting)
│   ├── index.html
│   ├── tokens.css           # Cores contabilidade
│   └── copy-pt-BR.md        # Copy brasileira específica
│
├── investimentos/           # Base: Wealth Mgmt + Investment Mgmt
│   ├── index.html
│   ├── tokens.css           # Cores investment
│   └── copy-pt-BR.md        # Copy para gestoras/advisors
│
├── fintech-saas/            # Base: Payment Solution + Cloud Software
│   ├── index.html
│   ├── tokens.css           # Cores fintech
│   └── copy-pt-BR.md        # Copy para fintechs/SaaS
│
└── banking/                 # Base: Online Banking + Payment Solution
    ├── index.html
    ├── tokens.css           # Cores banking
    └── copy-pt-BR.md        # Copy para bancos/neobanks
```

Cada um vira um **template reutilizável** que você clona, muda copy + imagens + cores = pronto pro cliente.
