## Recursos visuais

**Cores:**
- Primária: #864ffe (Púrpura/Magenta)
- Secundária: #1a1a1c / #0f1217 (Cinza muito escuro, quase preto)
- Accent: #fcfcfc / #fcfcfd (Branco/Off-white)
- Verde: #c6f56f (Verde fluorescente - call-to-action)
- Amarelo: #f9eb57 (Amarelo ouro - destaques)
- Background claro: #f4f5f8 / #f9fafb (Cinza muito claro)
- Background escuro: #1b232f / #181d26 (Cinza escuro)

**Tipografia:**
- Fonte única: Inter Tight (weights: 100-900, suportando italic)
- Headings: Peso 600-700, size XL-4XL
- Body: Peso 400, size SM-BASE
- Taglines: Peso 400-500, size XS-SM

**Componentes chave:**
- Badges com verde ou amarelo (bg-ns-green, bg-ns-yellow)
- Botões em variações: btn-green, btn-secondary, btn-primary, btn-white
- Cards com rounded-[20px], border-radius uniforme em 14-20px
- Shadows: shadow-14, aplicados em dropdowns e elevações
- Gradients: linear gradients em hero e seções; múltiplas cores
- Animações: data-ns-animate com delays (0.1s+), ease-in-out 300-500ms
- Icons: SVG inline com stroke e fill dinâmicos

**Layout & Spacing:**
- Container max-w-[1440px] com padding responsivo
- Grid 12 colunas com gaps variáveis (6px-60px)
- Padding seções: 16px-100px vertical, 16px-96px horizontal
- Breakpoints: mobile, sm (640px), md (768px), lg (1024px), xl (1280px)

## Notas de qualidade

**Pontos fortes:**
- Altamente polido e pronto para produção (score 8/10)
- Suporte completo dark mode com classes TailwindCSS
- Mega-menu com submenu hover bridges (UX premium)
- 48+ páginas variadas com layouts consistentes
- Animações suaves com data-ns-animate (entrada em cascata)
- Mobile-first responsive + desktop optimizations
- Componentes reutilizáveis (cards, buttons, badges, modals)
- Tipografia única elegante, bem espaçada

**Limitações:**
- Requer JavaScript para: menus dropdown, swiper carrosséis, tabs, mobile sidebar
- Paleta púrpura+amarelo agressiva; melhor para fintech/startup, risco em B2B conservador
- Asset-heavy: 30+ imagens PNG/JPG + SVGs inline
- Sem formulários backend integrados (apenas UI)
- Sem sistema de componentes Storybook ou pattern library documentada

**Acessibilidade:**
- Aria labels presentes (nav, section headings, icon roles)
- Sr-only (screen reader only) para skip links e labels
- Semantic HTML: button, form, section, nav, footer
- Alt text em imagens
- Contraste light/dark testável via inspetor, mas paleta neutra em light mode é fraca em contraste (cinza + branco)

**Performance:**
- Sem lazy loading visível nas imagens
- CSS único (main.css): ~200KB minificado estimado
- JS único (main.js): Provavelmente Swiper.js + vanilla JS customizado (~50KB)
- Sem preload/prefetch de assets críticos visível no head

**Customização:**
- Tailwind utilities usadas extensivamente (fácil modificação via config)
- Custom icons com classes .ns-shape-* (geradas ou iconfont)
- Cores em CSS variables (--color-primary-500, etc.)
- Componentes bem isolados por data-* attributes (data-ns-animate, data-tab-button, etc.)
