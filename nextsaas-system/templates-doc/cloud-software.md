# Nexsas Cloud Software

Template premium de landing page para SaaS e soluções cloud. Estilo corporativo com gradientes suaves, animações de scroll e design responsivo total. Excelente para software B2B financeiro, ferramentas de produtividade e plataformas em nuvem.

### Tipografia
- **Fonte Principal**: Inter Tight (Google Fonts, @font-face via fonts/next-sass)
- **Weights**: 300 (light), 400 (normal), 500 (medium), 600 (semibold), 700 (bold)
- **Escalas de Texto**:
  - Heading 1: 4.25rem / 110% line-height
  - Heading 2: 3.25rem / 120%
  - Heading 4: 2rem / 130%
  - Heading 5: 1.5rem / 140%
  - Tagline 1: 1rem / 150%
  - Tagline 2: 0.875rem / 150%
  - Tagline 3: 0.75rem / 150%
- **Icon Font**: next-sass (@font-face, custom shapes ns-shape-*)

### Animações & Interações
- **data-ns-animate**: Atributo para scroll animations (fade-in, slide)
- **data-delay**: Delays progressivos (0.1s - 1.1s)
- **data-direction**: up, left, right (direção do slide)
- **data-offset**: Trigger offset em pixels
- **Dropdowns**: Mega-menu com pointer-events e opacity transitions
- **Counter Animations**: Números que incrementam (projects, clients)
- **Swiper/Marquee**: Logos em loop contínuo
- **Hover States**: Botões com transições color/scale

### Componentes Reutilizáveis
- **Buttons**: .btn classes (btn-primary, btn-secondary, btn-white, btn-transparent) com estados hover
- **Badges**: .badge (badge-white, badge-blur) com tipografia customizada
- **Cards**: Rounded-[20px], padding p-2.5, backgrounds camadas (white outer, background-X inner)
- **Avatars**: size-12 (48px), rounded-full, com rings/borders
- **Icons**: SVG inline + font-icons (ns-shape-*)
- **Spacing**: Baseado em 0.25rem (4px grid system Tailwind)

## Notas de qualidade

- **9/10 Qualidade Geral**
  - ✓ Código HTML semântico com aria-labels completos
  - ✓ CSS modular Tailwind (sem mixins bloatware)
  - ✓ Responsividade testada: mobile-first (min-[425px], sm, md, lg, xl, 2xl)
  - ✓ Dark mode nativo (class="dark" toggle)
  - ✓ SEO otimizado (meta tags Open Graph, Twitter, schema hints)
  - ✓ Lighthouse-ready (lazy loading images, preconnect fonts)
  - ✓ Animações performance-friendly (GPU-accelerated transforms)
  - ✓ Acessibilidade: form labels, alt text, semantic HTML
  
- **Pontos Fortes**
  - Design system consistente (espacemento, cores, tipografia)
  - Componentes compostos reutilizáveis
  - Suporte nativo light/dark mode
  - Mega-menu com UX sofisticado
  - Animações scroll orchestradas (delays progression)
  - Pricing table com comparação visual (checkmarks)
  - 40+ páginas pré-construídas (eco-system completo)

- **Limitações**
  - Conteúdo dummy em várias seções (Lorem ipsum reviews)
  - Gradientes hardcoded em inline styles (baixa manutenibilidade em escala)
  - Sem suporte inicial a temas beyond light/dark (prefers-color-scheme somente)
  - Emails/formulários conectados a placeholder (sem backend integrado)
  - Imagens estaticamente referenciadas (sem CDN/lazy load completo)
  - Sem componentes headless (React/Vue components não fornecidos)

- **Performance Notes**
  - CSS: 13.2KB (main.css) + Tailwind compiled
  - Fonts: Google Fonts (Inter Tight) + custom icon font (next-sass)
  - Images: ~50+ PNGs + SVGs (não otimizados, considerar WebP)
  - JS: Scroll animations (data-ns-animate), theme toggle, counter logic
  - Recomendação: Deploy com CDN, gzip CSS/JS, convert images para WebP
