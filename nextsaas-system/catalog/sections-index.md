## Seções Típicas Encontradas

Cada template contém uma combinação das seções abaixo. O catálogo vai mapear cada uma com suas variantes:

### Estrutura Padrão de Landing

1. **Navigation** — Header com nav, logo, buttons
   - Variantes: pill floating, sticky, mega-menu, hamburger
   
2. **Hero** — Headline + CTA + visual
   - Variantes: gradiente, vídeo, parallax, ilustração, animação
   
3. **Social Proof** — Logos clientes, stats, badges
   - Variantes: marquee, grid, carousel
   
4. **Features** — Diferenciais principais
   - Variantes: grid 3-col, tabs, cards com hover, before/after, accordion
   
5. **Services** — Ofertas/serviços
   - Variantes: cards com ícones, list com checkmarks, grid assimétrico
   
6. **Pricing** — Tiers de preço
   - Variantes: toggle mensal/anual, 3-4 colunas, comparison table, featured tier
   
7. **Testimonials** — Reviews/depoimentos
   - Variantes: carousel, grid, flip cards, marquee, stars
   
8. **FAQ** — Perguntas frequentes
   - Variantes: accordion, 2-column, categorizado, collapsible
   
9. **CTA** — Call to action
   - Variantes: newsletter, trial signup, demo booking, contact form
   
10. **Footer** — Rodapé
    - Variantes: multi-coluna, minimal, mega-footer, sticky

11. **About/Team** — Sobre a empresa
    - Variantes: timeline, team grid com fotos, values cards, company story

12. **Integration** — Integrações/parceiros
    - Variantes: logo grid, marquee, orbit animation, categorizado

13. **Blog** — Artigos/notícias
    - Variantes: grid, list, featured + recent, card designs

## Como o Catálogo é Organizado

```
catalog/
├── sections-index.md          # Este arquivo (índice)
│
├── hero/
│   ├── hero-gradient.html    # Variante 1: com gradiente
│   ├── hero-video.html       # Variante 2: com vídeo
│   ├── hero-parallax.html    # Variante 3: com parallax
│   └── README.md             # Notas de cada variante
│
├── pricing/
│   ├── pricing-toggle.html   # Variante 1: toggle mensal/anual
│   ├── pricing-table.html    # Variante 2: tabela comparativa
│   └── README.md
│
├── features/
│   ├── features-grid.html
│   ├── features-tabs.html
│   └── README.md
│
└── [outras seções...]
```

Cada seção terá:
- **HTML isolado** — copiável direto
- **CSS** — incluído ou via `tokens.css`
- **Variantes** — 2-4 opções por tipo
- **Origem** — qual template vem
- **Notas** — dependencies, customização

## Exemplo: Como Montar um Site

**Seu pedido:**
```
"Quero site pra SaaS de gestão de projetos.
Seções: Hero (video), Features (grid), Pricing (toggle), CTA, Footer.
Azul #2563eb, sem blog."
```

**IA faz:**
1. Procura no catálogo: `hero-video.html` (melhor match)
2. Procura: `features-grid.html` (do template similar)
3. Procura: `pricing-toggle.html`
4. Procura: `cta-newsletter.html`
5. Procura: `footer-minimal.html`
6. Monta na ordem: Hero → Features → Pricing → CTA → Footer
7. Aplica `tokens.css` com azul #2563eb
8. Substitui copy placeholder
9. Gera em `sites/projeto-tasks/index.html`

Resultado: **site pronto em minutos**, não horas.
