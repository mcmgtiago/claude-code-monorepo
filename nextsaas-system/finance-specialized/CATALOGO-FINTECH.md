## Seções Mais Relevantes para Fintech

### 🏆 Top Seções (usar sempre)

1. **Hero com credibilidade** — avatars + counter "99+ companies" + CTA
2. **Trust badges** — compliance logos (SOC2, PCI-DSS, ISO 27001)
3. **Stats com counters** — $X bilhões, X% crescimento, X+ clientes
4. **Security section** — encryption, 2FA, auditing
5. **Integration marquee** — logos de bancos, fintechs, APIs
6. **Testimonials** — com nome/cargo de CTOs/CFOs
7. **Pricing** — toggle mensal/anual com comparison table
8. **FAQ** — compliance, segurança, taxas

### ⚡ Seções Diferenciadas (impacto alto)

1. **Dashboard mockup** — screenshot/mockup do produto
2. **ROI calculator** — input + output de benefícios
3. **Process steps** — onboarding simplificado
4. **Live data preview** — ticker/chart animado
5. **Case study cards** — ROI real de clientes
6. **Awards/badges** — Deloitte Fast 50, Forbes, etc.
