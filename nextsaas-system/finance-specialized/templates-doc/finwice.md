# FinWice Fintech Platform

FinWice é um template HTML completo e profissional para empresas de consultoria financeira, planejamento de investimentos e serviços de gestão de riqueza. Apresenta design moderno com navegação extensiva, animações suaves, sliders interativos e múltiplas variações de páginas para diferentes nichos (consultoria estratégica, transformação digital, consultoria em seguros, consultoria tributária, etc.).

## Seções encontradas (index.html)

1. **Top Bar** — Endereço, email, seletor de idioma (EN/VN), telefone, ícones redes sociais
2. **Header** — Logo, navegação principal com mega-menu de 9 variações de home, submenu de serviços/casos/páginas/loja/blog, botão CTA, ícones de busca/carrinho/menu
3. **Hero Slider** — Carrossel de 3 slides com fade effect, títulos dinâmicos, subtítulos e CTA "View All Services"
4. **About Section** — Conteúdo sobre empresa com animação de onda de texto, card com contador (20+ anos), tabs (Expertise/Innovation/Commitment)
5. **Benefits Section** — 4 cards com ícones (Tailored Strategies, Investment Growth, Financial Security, Tax Savings) com animações staggered
6. **Services Section** — Tabs com 4 serviços (Retirement Planning, Investment Advisory, Estate Planning, Tax Optimization), cada um com imagem, descrição e lista de benefícios
7. **Process Section** — 4 steps em grid (Assessment → Goal Setting → Plan Development → Ongoing Review) com ícones SVG e hover effects
8. **Case Studies/Projects** — Slider swiper com 4 case studies + galeria de imagens paralela interativa
9. **Testimonials** — Slider com 3 cards, cada um mostrando contador percentual + feedback + avatar/nome/cargo
10. **FAQs** — Acordeão com 5 questões financeiras, split layout (conteúdo + acordeão)
11. **Blog Section** — Slider com 3 posts recentes, cada um com imagem/data/categoria/título/descrição
12. **Awards Section** — Grid de 5 badges/certificações com fade-in animation
13. **CTA Section** — Imagem + conteúdo branco sobre background escuro, contato direto
14. **Footer** — Logo, descrição, contato, 2 colunas de links (Categories/Quick Links), newsletter subscription, ícones sociais

## Recursos e diferenciais visuais

**Animações:**
- Text wave animations (text-anime-wave)
- Fade-in effects com WOW.js (wow fadeInUp)
- Staggered delays em lists
- Hover states em cards e buttons
- Swiper sliders com fade effect
- Counter animations com Odometer.js
- ScrollTrigger/GSAP para parallax

**Layouts especiais:**
- Mega-menu com imagens e previews de home variants
- Tabbed content com smooth transitions
- Dual-gallery interactive (projects + images synchronized)
- Split sections (left content + right media)
- Split FAQs (heading + accordion)
- Responsive grid transforms em mobile/tablet

**Componentes:**
- Custom select (Nice Select)
- Swiper carousel (4 configs: projects, testimonials, posts, generic)
- Accordion collapse (Bootstrap)
- Counter display (Odometer)

**Gráficos/dados financeiros:**

- Award badges/certifications

## Notas de qualidade

**Pontos fortes:**
- Estrutura de código limpa com classes semânticas bem nomeadas
- Multi-página com variações temáticas (9 niche variants)
- Animações refinadas sem excesso
- Responsive design (mobile-first approach com breakpoints claros)
- Loading otimizado com lazy-load de imagens
- Navegação intuitiva com mega-menu visual
- Bootstrap 5 + custom CSS bem organizado
- Bibliotecas modernas (GSAP, Swiper, AOS)
- Fallback para RTL (toggle-rtl no topo)

**Pontos fracos:**
- Alguns blocos de descrição/copy repetidos (serviços, testemunhos)
- Formulários sem validação backend aparente
- Placeholder content em várias seções (emails de demo, números fictícios)
- One-page variants existem mas integração poderia ser mais fluida
- Sem indicação de otimização SEO (meta tags básicas)
- Imports de fontes via Google Fonts (5 famílias + fallbacks = overhead)

**Score:** 8/10 — Profissional, bem-estruturado, animações polidas, múltiplas variações de nicho. Perde pontos por repetição de copy e falta de validação/otimização avançada, mas funciona muito bem como template corporativo fintech out-of-the-box.
