## Diferença entre v1 e v2

A v1 focava principalmente em:
- Posicionamento
- Copy
- Estrutura de seções
- Tema visual geral

A v2 adiciona:
- Aesthetic moves específicos
- Componentes premium nomeados
- Motion system por prompt
- Hero visual mais forte
- Interações e efeitos
- Checklist de qualidade
- Sugestões de Pexels específicas
- Mais clareza de implementação

---

## Como usar

1. Escolha o subnicho de RH.
2. Abra o prompt v2 correspondente.
3. Troque `[NOME]`, cases, métricas e CTAs para seu cliente.
4. Use o [../00-PROMPT-MASTER-v2.md](../00-PROMPT-MASTER-v2.md) como base técnica global.
5. Use o [../GUIA-DE-REFINO-VISUAL-E-EFEITOS.md](../GUIA-DE-REFINO-VISUAL-E-EFEITOS.md) para elevar o visual ainda mais.

---

## Padrão visual mínimo esperado

Todo prompt v2 deve gerar uma landing page que contenha pelo menos:

- Hero com mídia viva ou UI mockup forte
- Headline com BlurText ou reveal premium
- Um bento grid
- Uma seção de métricas com counters
- Cases com dados realistas
- FAQ premium
- CTA final forte
- Microinterações em cards e botões
- Responsividade completa
- Reduced motion respeitado

---

## Stack recomendada

- React 18 + Vite + TypeScript
- Tailwind CSS v4
- motion/react
- lucide-react
- Radix UI para accordion/tabs/dialog
- hls.js se usar vídeo HLS
- Pexels/Unsplash para mídia
