# Kit Mestre — Sites Premium

Este kit foi preparado para iniciar projetos de landing pages e sites institucionais com o mesmo nível de cuidado visual do projeto eGestor: direção criativa, animações em todas as seções importantes, código organizado, responsividade e acabamento técnico de lançamento.

## Como usar em uma nova conversa

1. Anexe este ZIP.
2. Cole o conteúdo de `01-PROMPT-RAPIDO.txt`.
3. Envie o material do cliente: textos, logo, fotos, vídeos, contatos e links.
4. Envie referências visuais somente quando existirem. Elas são opcionais.
5. Aguarde primeiro o planejamento visual e estrutural.
6. Aprove o planejamento.
7. Solicite a construção, publicação e entrega do ZIP final.

## Arquivos principais

- `CLAUDE.md`: instruções operacionais do projeto, incluindo quando usar cada skill global.
- `01-PROMPT-RAPIDO.txt`: prompt enxuto para iniciar qualquer projeto.
- `02-PROMPT-MESTRE-COMPLETO.md`: especificação completa para projetos importantes.
- `03-BRIEFING-CLIENTE.md`: formulário opcional para organizar o material.
- `04-CHECKLIST-DE-QUALIDADE.md`: padrão mínimo antes da entrega.
- `05-MODULO-GREEN-HAT-AEC.md`: regras específicas da Green Hat para arquitetura, engenharia e construção.
- `starter-code/`: base React/Next.js com Motion, SEO e conteúdo centralizado, quando estiver incluída no projeto.
- `references/`: bibliotecas do Motion Sites, 21st.dev, HorizonX e Superdesign.

## Ordem das referências

Ao escolher padrões visuais ou mecânicas de animação:

1. Motion Sites: principal fonte de direção de landing pages, SaaS e motion.
2. 21st.dev: componentes, efeitos, cards, shaders e microinterações.
3. HorizonX: experiências avançadas, 3D, WebGL e interfaces experimentais.
4. Superdesign: canvas, física, interação e conceitos complementares.

## Regra importante

Projetos demonstrativos devem ser apresentados como conceitos. Nunca invente clientes, resultados, depoimentos, prêmios ou números que não tenham sido fornecidos.

## Skills globais recomendadas

Este kit foi preparado para trabalhar junto com as skills globais instaladas em `~/.claude/skills/`. Em cada projeto, use-as como camadas de especialização:

- `/design-taste-frontend` para direção visual inicial de landing pages, portfolios e redesigns.
- `/redesign-existing-projects` quando houver um site ou app existente para melhorar.
- `/impeccable` para craft, polish, auditoria final, layout, tipografia, responsividade e acabamento premium.
- `/audit-typography` e `/suggest-improvements` para revisar ou definir tipografia.
- `/find-animation-opportunities`, `/improve-animations`, `/review-animations`, `/animation-vocabulary`, `/apple-design` e `/emil-design-eng` para motion, microinterações e sensação de interface.
- `/pick-ui-library` para escolher bibliotecas de UI quando surgir uma necessidade específica.

Quando o projeto for novo, entregar primeiro **nav + hero + 2ª seção**. Para avaliação de direção, criar **4 variantes de hero realmente distintas**, alternáveis na própria página por seletor visível.
