# Premium Landing Page Skill (Claude Code)

Este arquivo configura a skill no Claude Code (local).

Ver o plugin completo em:
`C:\Users\Administrator\AppData\Roaming\Open Design\namespaces\release-stable-win\data\plugins\premium-landing-motion`

## Uso no Claude Code

```bash
/premium-landing-motion
```

Ou mencione:
- "landing page premium"
- "site premium com motion"
- "landing cinematográfica"

## Inputs

**Obrigatórios:**
- `brand_name` — Nome da marca
- `tagline` — Proposição de valor

**Opcionais:**
- `theme` — dark | light | editorial
- `industry` — consultoria, tech, saas, etc
- `sections_count` — 6-16, default 12
- `has_pricing` — true | false
- `has_video_hero` — true | false
- `language` — pt-BR | en | es

## Output

React + Vite project com:
- Componentes premium (BlurText, FadeUp, LiquidGlass, Marquee, etc)
- Framer Motion animations
- Tailwind CSS v4
- Dark/light mode
- WCAG AA compliant
- Lighthouse 90+

## Exemplos

```
Usuário: Crie uma landing page premium de consultoria de RH
      com tema editorial, animações de alta qualidade
Claude: [Usa skill premium-landing-motion]
```

```
Usuário: Landing cinematográfica para agência criativa
        Tema: dark, seções: 14, com hero vídeo
Claude: [Cria com motion_intensity: 1.0]
```
