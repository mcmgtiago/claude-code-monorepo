# NEXO (Contabilidade)

**AI Operating System para Contadores.**

8 skills para gestão de clientes, controle de obrigações fiscais, análise tributária e compliance.

Para começar: `/office-setup`

---

## ✅ O que você consegue fazer

### Gestão de Clientes

- **`/client-profile`** — Cadastro fiscal completo (CNPJ, regime, faturamento, obrigações por regime)
- **`/billing-tracker`** — Faturamento, cobrança, inadimplência

### Compliance & Obrigações

- **`/obligation-tracker`** — Calendário fiscal: SPED, eSocial, ECF, IRPF, MEI DAS. Alertas 60d/30d/7d/1d.
- **`/compliance-checker`** — Auditoria de conformidade + risk detection

### Análise Fiscal

- **`/financial-summary`** — Resumo mensal por cliente (receita, deduções, alertas)
- **`/tax-optimization`** — Análise de melhor regime tributário + deduções

### Operacional

- **`/office-setup`** — Onboarding do escritório
- **`/content-creator`** — Posts fiscais educativos
