# EIXO — sistema de marca

## Tokens

```css
:root {
  --bg: oklch(0.958 0.006 95);
  --surface: oklch(0.978 0.006 95);
  --fg: oklch(0.18 0.012 145);
  --muted: oklch(0.43 0.014 145);
  --border: oklch(0.18 0.012 145 / 0.14);
  --accent: oklch(0.9 0.17 122);
}
```

Equivalências fornecidas: `--ink #101311`, `--ink-soft #49504a`, `--paper #f4f3ef`, `--paper-strong #faf9f5`, `--paper-muted #e8e7e1`, `--signal #c7f36a`, `--signal-deep #a6d94b`, `--clay #e96a4a`, `--success #7dbd56`, `--dark-card #171a17`.

## Tipografia

- Display: `Instrument Serif`, Georgia, serif; somente em itálico e como ênfase editorial.
- Corpo: `Manrope`, ui-sans-serif, system-ui, sans-serif.
- Técnico: `DM Mono`, ui-monospace, monospace.

## Postura

- Alternar papel quente e superfícies profundas como capítulos, não decoração.
- Usar verde-lima como sinal de progresso ou ação; máximo de dois focos por tela.
- Reservar laranja-terra para tensão, risco ou dado crítico.
- Preferir linhas, grids, nodos e grandes áreas de respiro a conjuntos de cards.
- Movimento comunica entrada, mudança de estado ou progressão; nunca ornamentação contínua.
