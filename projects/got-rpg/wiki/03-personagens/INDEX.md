## NPCs Recorrentes

Personagens não-jogáveis que aparecem **múltiplas vezes** ou são
**central para o arco**.

### Aliados notáveis

- (exemplo: Davos Seaworth, capitão honrado)
- (exemplo: Brienne de Tarth, guerreira de honra)

### Antagonistas notáveis

- (exemplo: Cersei Lannister, rainha manipuladora)
- (exemplo: Ramsay Bolton, torturador)

### Romance / Interesse

- (exemplo: Margaery Tyrell, cortesã política)
- (exemplo: Ygritte, selvagem do Muro)

### Mentor / Guia

- (exemplo: Maester Luwin, conselheiro)
- (exemplo: Melisandre, sacerdotisa misteriosa)

> Crie fichas usando [`template-npc.md`](template-npc.md).

## Como manter este hub

1. Toda vez que um NPC novo é importante, crie uma ficha em
   `npcs/nome-npc.md`.
2. Atualize as listas acima para refletir a campanha.
3. Marque NPCs como "mortos" quando forem.
