🎯 OBJETIVO
───────────────────────────────────────────────────────────────────────────────
Gerar uma landing page profissional, moderna e acessível para a NEXUS People
Strategy com 9 seções completas, animações elegantes e conversão otimizada.


📋 AS 9 SEÇÕES
───────────────────────────────────────────────────────────────────────────────

01. HERO — Editorial Minimalista
    ├─ SignalMap interativo (SVG com alinhamento organizacional)
    ├─ WordReveal na headline com stagger
    ├─ 2 CTAs (primary + outline)
    └─ Layout grid 12-col: texto esquerda, visual direita

02. TENSÕES — O Custo do Desalinhamento
    ├─ Headline com palavra em serif itálica verde
    ├─ 3 cards empilhados com hover effects
    ├─ Números animados com transição de cor
    └─ Ícone ArrowUpRight que aparece ao hover

03. FRENTES — Frentes de Atuação
    ├─ Background escuro (#1a1a1a)
    ├─ Seletor de 3 serviços com painel animado
    ├─ AnimatePresence na troca (fade + slide)
    ├─ Outcomes com ícones Check
    └─ Mobile: vira accordion

04. MÉTODO — Método NEXUS
    ├─ Timeline sticky ao scroll (desktop)
    ├─ 4 etapas: Mapear → Direcionar → Implantar → Consolidar
    ├─ useScroll + useTransform para progress bar
    ├─ Painel com ícone, número, nome, duração, descrição
    └─ Mobile: 4 cards empilhados com linha vertical

05. RESULTADOS — Resultados que Viram Rotina
    ├─ Background escuro com glow verde
    ├─ 3 cases com seletor vertical (Skala, Onda, Vereda)
    ├─ MetricTicker animado para cada métrica
    ├─ Delta pills com direção (up/down)
    └─ Barras comparativas animadas

06. FORMATOS — Formas de Parceria
    ├─ 3 cards side-by-side (desktop) / empilhados (mobile)
    ├─ Card do meio com badge verde "Mais indicado"
    ├─ Badge + Número + Título + Duração + Descrição
    ├─ Lista de entregas com ícones Check
    └─ Hover: translate-y -1px + shadow

07. DEPOIMENTOS — Quem Viveu o Processo
    ├─ Carousel manual SEM autoplay
    ├─ Citação em Instrument Serif italic grande
    ├─ Aspas decorativas no canto (branco 10% opacidade)
    ├─ 2 botões circulares (prev/next)
    ├─ Indicador "01/03"
    ├─ Barra de progresso com 3 segmentos
    └─ Suporte a setas do teclado

08. FAQ — Perguntas Diretas
    ├─ 6 perguntas em accordion
    ├─ Apenas 1 aberto por vez
    ├─ Chevron rotaciona ao abrir/fechar
    ├─ AnimatePresence com height + opacity
    └─ Respostas em var(--ink-soft), max-width 760px

09. CTA + FOOTER — Começar com Clareza
    ├─ CTA FINAL
    │  ├─ Background escuro + grid + glow verde
    │  ├─ Headline com "menos nebulosa" em serif itálica verde
    │  ├─ Formulário com 5 campos + checkbox
    │  ├─ Validação Zod (email, required, min length)
    │  ├─ Estados: normal → loading → sucesso
    │  └─ Dados de contato: email + localização
    │
    ├─ FOOTER
    │  ├─ Background #0c0e0c (mais escuro)
    │  ├─ 4 colunas: Logo + Nav + Conteúdo + Legal
    │  ├─ Links com hover color transition
    │  └─ Rodapé com copyright + tagline
    │
    └─ NAVBAR (fixa em todas as páginas)
       ├─ Scroll 0: fundo transparent, texto branco/ink
       ├─ Scroll > 60px: fundo blur + border, sticky top
       ├─ Border-radius full, max-width adaptativo
       ├─ Logo esquerda + Nav centro + CTA direita
       └─ Mobile: hamburger com drawer fullscreen

🚀 COMO USAR
───────────────────────────────────────────────────────────────────────────────
1. Criar projeto: npm create vite@latest nexus -- --template react-ts
2. Instalar deps: npm install tailwindcss motion/react lucide-react zod
3. Copiar App.tsx gerado → src/components/App.tsx
4. Iniciar: npm run dev
5. Acessar: http://localhost:5173
