## Instruções de uso

1. **Copie o template acima**
2. **Substitua**:
   - [LOGO DA SUA AGÊNCIA] → imagem/PNG do logo
   - [NOME DA EMPRESA] → nome do cliente
   - [SEU NOME] / [SUA AGÊNCIA] → seus dados
   - [PACOTE] → escolher START, SCALE ou DOMINA
   - [VALORES] → confirmar preços do doc 03
   - [DIA/HORA] → data/hora real pra reunião
3. **Exporte como PDF** (Google Docs ou Word → PDF)
4. **Envie por e-mail + WhatsApp**
5. **Negocie se necessário**, mas não fuja dos preços base — ajuste escopo em vez disso (ex: tirar TikTok Ads = menos R$ 200/mês)
