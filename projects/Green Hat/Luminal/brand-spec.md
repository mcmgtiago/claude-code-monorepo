# Luminal Studio · especificação observada

Sistema escuro cinético: preto quase absoluto, tipografia geométrica Syne, corpo Inter, grade técnica fina e um único vermelho luminoso.

```css
:root {
  --bg: oklch(0.145 0 0);
  --surface: oklch(0.205 0 0);
  --fg: oklch(0.97 0 0);
  --muted: oklch(0.708 0 0);
  --border: oklch(0.269 0 0);
  --accent: oklch(0.637 0.237 25.331);
}
```

- Display: `"Syne", sans-serif`.
- Corpo: `"Inter", sans-serif`.
- Mono: `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`.
- Postura: grade de quatro colunas permanece visível como estrutura.
- Postura: superfícies retas e bordas finas dominam; raios aparecem só em controles.
- Postura: vermelho é energia e foco, não preenchimento de grandes áreas.
- Postura: imagens ocupam células inteiras e mantêm contraste alto.
- Postura: movimento é linear/cinético, com pausas apenas em hover do marquee.
