## TCC (Terapia Cognitivo-Comportamental)

### Técnicas Cognitivas

| Técnica | Descrição | Quando Usar |
|---------|-----------|-------------|
| **Reestruturação cognitiva** | Identificar, questionar e modificar pensamentos disfuncionais | Crenças rígidas, distorções |
| **Registro de pensamentos** | Situação → pensamento → emoção → evidências → alternativa | Monitoramento diário |
| **Questionamento socrático** | Perguntas que guiam o paciente a reavaliar | Exploração de crenças |
| **Seta descendente** | "E se isso fosse verdade, o que significaria?" | Acessar crenças centrais |
| **Teste de evidências** | Listar provas a favor e contra uma crença | Crenças intermediárias |
| **Descatastrofização** | "Qual o pior cenário? E o mais provável?" | Ansiedade antecipatória |
| **Reatribuição** | Redistribuir responsabilidade/causa | Culpa excessiva |
| **Psicoeducação** | Explicar modelo cognitivo ao paciente | Início do tratamento |

### Técnicas Comportamentais

| Técnica | Descrição | Quando Usar |
|---------|-----------|-------------|
| **Ativação comportamental** | Programar atividades prazerosas/de domínio | Depressão, anedonia |
| **Exposição gradual** | Hierarquia de medos + enfrentamento sistemático | Fobias, evitação |
| **Exposição com prevenção de resposta (EPR)** | Exposição ao gatilho SEM realizar compulsão | TOC |
| **Experimentos comportamentais** | Testar predições catastróficas na prática | Crenças rígidas |
| **Relaxamento progressivo (Jacobson)** | Tensão/relaxamento muscular sistemático | Ansiedade somática |
| **Respiração diafragmática** | 4-7-8 ou 4-4-4-4 | Pânico, ansiedade aguda |
| **Treino de habilidades sociais** | Role-play + feedback + prática real | Fobia social, assertividade |
| **Dessensibilização sistemática** | Relaxamento + exposição imaginária gradual | Fobias |
| **Modelagem** | Demonstrar comportamento adaptativo | Crianças, habilidades novas |

### Técnicas de 3ª Onda

| Técnica | Abordagem | Descrição |
|---------|-----------|-----------|
| **Defusão cognitiva** | ACT | "Observar pensamento sem se fundir" |
| **Valores e ação comprometida** | ACT | Identificar valores + agir alinhado |
| **Mindfulness (atenção plena)** | MBCT/ACT | Observação não-julgadora do presente |
| **Regulação emocional** | DBT | Nomear + aceitar + modular emoção |
| **Tolerância ao distress** | DBT | Suportar sofrimento sem agir impulsivamente |
| **Eficácia interpessoal** | DBT | Comunicar necessidades sem destruir relação |

## Psicodinâmica

### Intervenções Clássicas

| Técnica | Descrição | Quando Usar |
|---------|-----------|-------------|
| **Livre associação** | Paciente fala sem censura; terapeuta escuta padrões | Exploração inconsciente |
| **Interpretação** | Oferecer significado oculto do material | Quando há material suficiente |
| **Clarificação** | Reformular/organizar o que paciente disse | Comunicação confusa |
| **Confrontação** | Apontar contradição entre o dito e o observado | Padrões defensivos |
| **Assinalamento** | Destacar algo que paciente pode não perceber | Atos falhos, repetições |
| **Análise da transferência** | Explorar como paciente reproduz padrões na relação terapêutica | Relação terapêutica estável |
| **Holding** | Sustentação empática sem interpretação prematura | Regressão, fragilidade |
| **Continência** | Receber/metabolizar afetos intensos do paciente | Crises, angústia intensa |

### Mecanismos de Defesa (Referência)

| Nível | Defesas | Maturidade |
|-------|---------|-----------|
| **Maduro** | Humor, sublimação, supressão, altruísmo | Adaptativo |
| **Neurótico** | Repressão, intelectualização, formação reativa, deslocamento, racionalização | Intermediário |
| **Imaturo** | Projeção, acting out, dissociação, idealização/desvalorização, identificação projetiva | Desadaptativo |
| **Psicótico** | Negação psicótica, projeção delirante, distorção | Grave |

## Humanista / Existencial

| Técnica | Descrição | Quando Usar |
|---------|-----------|-------------|
| **Escuta empática** | Compreensão sem julgamento | Sempre (base) |
| **Reflexão de sentimento** | Devolver o sentimento percebido | Validação |
| **Aceitação incondicional** | Postura de respeito independente do conteúdo | Autoestima, vergonha |
| **Congruência** | Terapeuta é autêntico na relação | Transparência, vínculo |
| **Focalização (Gendlin)** | Atenção ao "sentido corporalmente sentido" | Dificuldade de nomear emoções |
| **Cadeira vazia (Gestalt)** | Diálogo com parte de si ou outra pessoa | Conflitos internos, luto |
| **Amplificação** | Intensificar gesto/expressão para acessar emoção | Alexitimia, bloqueio |
| **Análise existencial** | Explorar: sentido, liberdade, solidão, morte | Crise de sentido |
| **Logoterapia** | Encontrar sentido no sofrimento (Frankl) | Luto, doenças crônicas |

## Sistêmica / Familiar

| Técnica | Descrição | Quando Usar |
|---------|-----------|-------------|
| **Genograma** | Mapa multigeracional de padrões | Início, compreensão sistêmica |
| **Escultura familiar** | Posicionar membros no espaço | Dinâmica de poder/proximidade |
| **Reframing (reenquadramento)** | Dar novo significado ao comportamento | Romper ciclo de culpa |
| **Prescrição de tarefa** | Tarefa paradoxal ou direta | Quebrar padrão |
| **Pergunta circular** | "O que [membro B] acha quando [membro A] faz X?" | Empatia, perspectiva |
| **Externalização** | Separar problema da pessoa | Crianças, narrativa |
| **Mapa de alianças** | Quem está com quem? Contra quem? | Triangulação, coalizões |
| **Ritual terapêutico** | Ação simbólica para marcar transição | Luto, transições |

## Neuropsicologia (Reabilitação)

| Técnica | Foco | Quando |
|---------|------|--------|
| **Treino cognitivo** | Atenção, memória, funções executivas | Pós-AVC, TDAH, envelhecimento |
| **Compensação** | Estratégias externas (agenda, alarme, checklist) | Déficit irreversível |
| **Restauração** | Exercícios repetitivos para recuperar função | Déficit reversível |
| **Psicoeducação familiar** | Ensinar familiares sobre o quadro | Demência, TCE |
