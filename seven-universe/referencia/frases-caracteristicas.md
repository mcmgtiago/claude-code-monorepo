## 🎭 Espíritos — Frases Icônicas

### 🔥 Ignis
```
"A luz purifica o que a escuridão manchou."
"Ignis vê. Ignis age."
"Ordem acima de tudo!"
"Purifica!"
```

### ⚫ Umbra
```
"Ordem é só caos que desistiu."
"Oba. Sangue."

```
"O frio preserva. A estratégia vence."

```

```

"Deixa comigo! VAI!"
"Ninguém é mais rápido que eu!"
"Você chegou atrasado... de novo." (para Terra)

### 🌪️ Ventus
```
"O vento não tem dono. Mas às vezes escolhe um lado."

O tempo passa. Eu não."
"E aí, sumido!"
```

## 🌟 Frases de Bankai (Ativação)

Quando Seven ativa o Bankai, os espíritos falam em sequência:

```
Ignis:      "A chama branca acende para guiar."
Umbra:      "A chama negra consome para revelar."
Crystallis: "O frio preserva a forma."
Voltus:     "O raio move o mundo."
Ventus:     "O vento carrega o que quiser."
Terra:      "A terra sustenta."
Maris:      "A água adapta."
Lux:        "A luz revela tudo."
Vorax:      "...E o vazio espera por todos."
Seven:      "Tríplice infinita — manifesta."
```
