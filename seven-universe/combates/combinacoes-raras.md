## ⚔️ Combinações de 2 Espíritos

### Ofensivas

| Combinação | Nome | Efeito |
|-----------|------|--------|
| **Ignis + Voltus** | Chamas Elétricas Sagradas | Raios de fogo branco que purificam e paralisam |
| **Umbra + Voltus** | Relâmpago Negro | Teleporte + corrosão instantânea |
| **Ignis + Umbra** | Eclipse Flamejante | Fogo branco e negro fundidos (raro, brigam) |
| **Voltus + Ventus** | Tempestade Caótica | Velocidade absoluta + imprevisibilidade |
| **Terra + Ignis** | Vulcão Sagrado | Lava sagrada + terremoto purificador |
| **Umbra + Vorax** | Fim Absoluto | Corrosão + apagamento (devastador) |

### Defensivas

| Combinação | Nome | Efeito |
|-----------|------|--------|
| **Crystallis + Terra** | Muralha Eterna | Gelo + pedra = defesa impenetrável |
| **Ignis + Crystallis** | Barreira Dual | Fogo sagrado + gelo = defesa total |
| **Maris + Terra** | Mar de Pedra | Adaptação + força = imobilização |
| **Lux + Crystallis** | Prisão de Luz | Gelo luminoso que revela e prende |

### Utilidade

| Combinação | Nome | Efeito |
|-----------|------|--------|
| **Maris + Lux** | Cura Reveladora | Cura + revela a causa da ferida |
| **Ventus + Maris** | Tsunami Aéreo | Controle total de fluidos |
| **Lux + Ignis** | Purificação Total | Remove qualquer maldição/controle |
| **Maris + Crystallis** | Gelo Líquido | Congela em formas líquidas impossíveis |

## 🌌 Combinação Total (9 Espíritos)

Só possível no **Bankai**.

### "Tríplice Infinita" — Todos os 9

**Visual:**
- Lâmina brilha em 9 cores simultâneas
- Ambiente se transforma completamente
- Cada corte carrega todos os elementos

**Efeito:**
- Dano absoluto (físico + espiritual + existencial)
- Defesa total (todos os escudos ativos)
- Velocidade infinita (Voltus + Ventus)
- Regeneração eterna (Maris)
- Estratégia perfeita (Crystallis)
- Proteção total (Terra)
- Revelação de fraquezas (Lux)
- Corrosão inevitável (Umbra)
- Devoração de tudo (Vorax)
- Purificação final (Ignis)

**Duração:** Drena 5 minutos do tempo total do Bankai por uso.

## ⚠️ Combinações Proibidas

Combinações que Seven **não deve usar** ou que são instáveis.

| Combinação | Risco |
|-----------|-------|
| **Vorax solo (longo demais)** | Possessão hollow |
| **Ignis + Umbra (sem controle)** | Se cancelam, anulam poder |
| **Vorax + Todos os 8** | Vorax pode consumir os outros |
| **Lux + Vorax** | Paradoxo existencial (luz + vazio) |

### Vorax Solo — O Maior Risco

Se Seven usar Vorax sozinho por mais de 30 segundos:
- Veias negras começam a aparecer
- Olho esquerdo fica negro
- Vorax começa a sussurrar mais alto
- Os outros espíritos gritam para Seven parar

## 💥 Ataques Especiais Nomeados

### "Purificação Negra" (Ignis + Umbra)
```
Combinação dos rivais. Fogo branco + fogo negro fundidos.
Resultado: destruição + purificação simultâneas.
Seven só consegue ativar quando ambos cooperam (raríssimo).
```

### "Tempestade Eterna" (Voltus + Ventus + Maris)
```
Raios + vento + água = tempestade perfeita.
Cobre área inteira. Impossível fugir.
```

### "Muralha do Infinito" (Terra + Crystallis + Ignis)
```
Pedra + gelo + fogo sagrado = defesa que ataca quem toca.
```

### "Devoração Final" (Vorax + Umbra)
```
Sombra + vazio = buraco negro que consome tudo.
Último recurso. Muito perigoso.
```

### "Revelação do Destino" (Lux + Maris + Ventus)
```
Luz + água + vento = mostra o futuro do combate.
Seven vê todos os movimentos possíveis.
```
