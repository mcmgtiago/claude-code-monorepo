# 💬 Diálogos Típicos

Cenas de diálogo entre Seven e os espíritos em diferentes situações.

---

## 🎬 Cena 1: Despertando Shikai

```
Seven: "Acorde, Brasa do Infinito."

(A pulseira se dissolve. A lâmina começa a se formar.)

Ignis: "A chama branca acende. Vamos, mutante."

Umbra: "Chato. Sempre o mesmo discurso."

Crystallis: "Inimigo identificado. Plano: flanqueamento."

Voltus: "Plano? Que plano? VAI!"

Seven: "Voltus. Espere."

Voltus: "...Tá."

Ventus: "Hahaha, Voltus obedeceu."

Voltus: "CALA A BOCA VENTUS."
```

---

## 🎬 Cena 2: Primeira Vez com Vorax

```
(Seven está em perigo mortal. Os outros 8 espíritos estão enfraquecidos.)

Vorax: "...Finalmente."

Seven: "Quem..."

Vorax: "...Eu sou... o nono."

Seven: "Nono?"

Vorax: "...Sempre estive aqui. Esperando."

Seven: "O que você quer?"

Vorax: "...Comer. Apenas... comer."

Lux: (alerta) "Seven. Cuidado."

Seven: "...Que tipo de espírito é você?"

Vorax: "...O tipo que... acaba com as coisas."

(silêncio)

Vorax: "...Quer sobreviver? Deixe-me... sair."

Seven: "Se eu deixar... o que acontece?"

Vorax: "...Tudo acaba. Menos você."

Seven: "...Então venha. Mas eu comando."

Vorax: "...Por enquanto."
```

## 🎬 Cena 3: Ignis e Umbra Brigando

```
Ignis: "Você é tudo que está errado com o mundo!"

Umbra: "E você é tudo que é CHATO no mundo."

Ignis: "Disciplina! Ordem!"

Umbra: "Ordem é gaiola! Caos é liberdade!"

Crystallis: "Ambos errados. Estratégia é—"

Umbra: "Ninguém pediu sua opinião, gelo."

Crystallis: "..."

Terra: "..." (olha para ambos)

(silêncio)

Ignis: "...Tch."

Umbra: "...Whatever."

Ventus: "Vocês são um casal."

Ignis + Umbra: "NÃO SOMOS!"
```

---

## 🎬 Cena 4: Seven em Perigo

```
(Seven leva um golpe crítico.)

Terra: "ATRÁS DE MIM." (ergue muralha)

Maris: (já curando) "Água no ferimento. Não se mova."

Ignis: "QUEM FEZ ISSO?" (aura explode)

Umbra: (já na sombra do inimigo) "Achei."

Crystallis: "Três ferimentos. Dois superficiais. 
            Maris cuida. Terra protege. 
            Ignis e Umbra — ataquem. Juntos."

Ignis: "Com ELE?"

Umbra: "Com ELE?"

Crystallis: "AGORA."

(ambos atacam juntos, pela primeira vez cooperando)

Lux: (observando) "Quando Seven está em perigo... 
     até rivais cooperam."
```

## 🎬 Cena 5: Vorax Quase Domina

```
(Seven está perdendo o controle. Olho esquerdo fica negro.)

Vorax: "...Está... cansado? Eu... cuido."

Seven: "N...não..."

Vorax: "...Deixe ir. A dor... acaba."

Umbra: "Ei! Volta pra gaiola, vazio!"

Vorax: "...Você é caos. Eu sou... fim. Diferente."

Ignis: "SEVEN! NÃO OUÇA!"

Lux: (abre os olhos) "Seven. Você sabe quem é?"

Seven: "...Eu..."

Lux: "Diga."

Seven: "...Eu sou Seven."

Lux: "E o que Seven faz?"

Seven: "...Eu... comando."

(olho volta ao normal)

Seven: "VORAX. PRA DENTRO. AGORA."

Vorax: "...Como... quiser." (recua)

(silêncio)

Terra: (coloca a mão no ombro de Seven)

Seven: "...Obrigado, Terra."

Terra: "..."
```

## 🎬 Cena 6: Ativando o Bankai

```
Seven: "Aceito meu sangue, minha máscara, minha flecha."

(Asas brotam. Marca Quincy acende.)

Seven: "Mostrem-se, oito chamas..."

Ignis: "A chama branca acende para guiar."
Umbra: "A chama negra consome para revelar."
Crystallis: "O frio preserva a forma."
Voltus: "O raio move o mundo."
Ventus: "O vento carrega o que quiser."
Terra: "A terra sustenta."
Maris: "A água adapta."
Lux: "A luz revela tudo."

Seven: "...E você, voraz."

Vorax: "...E o vazio espera por todos."

Seven: "Tríplice infinita."

(Explosão de energia. Lâmina colossal se forma.)

Seven: "Eu sou Seven. Mutante, Hollow, Quincy.
        Vocês são minhas chamas. Eu sou a direção.
        MANIFESTA."
```

## 🎬 Cena 7: Fim do Bankai

```
(15 minutos se passaram. Seven colapsa.)

Ignis: "Até a próxima, Seven. Não me decepcione."

Umbra: "Dormiu bem? Brincadeirinha. Você caiu." (ri)

Crystallis: "Boa luta. Descanse." (some)

Voltus: "Quero revanche!" (some antes da resposta)

Ventus: "Já fui. Beijo." (já tinha sumido)

Terra: "...Cuida-se." (coloca mão no ombro e some)

Maris: "O fluxo continua. Até logo."

Lux: "Você é mais do que pensa, Seven." (sorri e some)

Vorax: "...Não... demore... pra voltar."

(Seven cai. 48 horas sem poderes.)
```

## 🎬 Cena 8: Ventus e Vorax Conversando

```
(Momento raro. Ventus visita Vorax no espaço interno.)

Ventus: "E aí, vazio."

Vorax: "...Ventus."

Ventus: "Não te vejo muito por aqui."

Vorax: "...Sempre estou aqui."

Ventus: "Sei. Quer jogar conversa fora?"

Vorax: "...O que... é conversa fora?"

Ventus: "Tipo... falar de nada."

Vorax: "...Nada é... meu domínio."

Ventus: "Hah! Boa."

(silêncio)

Vorax: "...Por que... não tem medo?"

Ventus: "Medo? De você?"

Vorax: "...Todos têm."

Ventus: "Eu sou vento. Não consigo ser preso. 
        Nem por medo."

Vorax: "...Interessante."

Ventus: "Além disso... você é parte do Seven. 
        E Seven é meu amigo."

Vorax: "...Amigo."

Ventus: "É."

Vorax: "...Não entendo."

Ventus: "Tudo bem. Não precisa."

(Ventus some. Vorax fica em silêncio.)

Vorax: "...Amigo."
```

## 🎬 Cena 9: Terra Fala Uma Frase Completa

```
(Momento extremo. Seven está à beira da morte real.)

(Todos os espíritos tentam ajudar.)

Ignis: "SEVEN! AGUENTA!"

Maris: (curando desesperadamente) "Não é suficiente!"

Crystallis: "Opções... zero."

Umbra: "MERDA!"

Voltus: "O QUE A GENTE FAZ?!"

Ventus: (sério pela primeira vez) "..."

Lux: (olhos abertos) "..."

Vorax: "...Dê-me... controle..."

Terra: "NÃO."

(Todos param. Terra nunca grita.)

Terra: "Seven. Não morra aqui."

(Pausa absoluta.)

Terra: "Eu sustento. Sempre sustentei. 
        Não vou parar agora."

(Terra ergue Seven com as próprias mãos de pedra.)

Terra: "...Levanta."

(Seven abre os olhos.)

Seven: "...Terra."

Terra: "..." (de volta ao silêncio)
```
