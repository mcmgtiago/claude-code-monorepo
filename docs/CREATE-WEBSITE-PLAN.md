# Create-Website Plan — Pachecho Putas Contabilidade

**Project:** Site institucional de escritório contábil.
**Goal primário:** Lead de contato (formulário/telefone) — não venda online.
**Stack:** HTML/CSS/JS puro, sem build.
**Craft level:** Funcional competente — visual clássico sério, não agência premium.

## Key Decisions

- **CTA primário:** "Fale com um contador" → formulário + telefone visíveis em todas as seções.
- **Tom:** Confiança, tradição, segurança — não disruptivo.
- **Idioma:** 100% pt-BR formal mas acessível.
- **Proof:** Sem depoimentos reais → usar placeholders marcados como ilustrativos, sem fabricar números.
- **Cor primária:** `#1e3a8a` (azul marinho corporativo).
