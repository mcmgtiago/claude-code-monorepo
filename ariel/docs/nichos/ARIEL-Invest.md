## 💔 Dores Detalhadas

### Dor #1: Não Escala (limite humano)
```
Consultor atende 40-50 clientes (máximo)
Cada cliente exige: relatório mensal + acompanhamento + educação
50 clientes × 3h/mês = 150h/mês (SÓ em manutenção)
Não sobra tempo pra captação de novos
```

### Dor #2: Cliente Ansioso ("e agora?")
```
Mercado caiu → cliente liga/manda msg
"Meus investimentos caíram! Devo vender?"
Consultor gasta 2h explicando a mesma coisa pra 20 clientes
```

### Dor #3: Onboarding Demorado
```
Cliente novo = 10-15h de trabalho antes de investir
- Coleta de dados pessoais
- Suitability (obrigatório CVM)
- Documentação KYC
- Planejamento inicial
```

### Dor #4: Churn Invisível
```
Cliente para de responder por 60 dias
Consultor não percebe (está sobrecarregado)
3 meses depois: "transferi meus investimentos pra outra assessoria"
Receita perdida: R$ 2.000/mês × 36 meses = R$ 72k
```

### Solução 3: **Educador de Investidor (Compliance CVM)**

**O que faz:** Responde dúvidas do cliente SEM dar recomendação (compliance). Educa com fatos e dados.

**Fluxo:**
```
Cliente: "O mercado tá caindo, devo vender minhas ações?"

ARIEL:
"Entendo a preocupação! O Ibovespa caiu 4.5% este mês.

📊 CONTEXTO:
• Sua carteira de ações: -3.2% no mês (melhor que mercado)
• Nos últimos 12 meses: +14% (acima da meta)
• Seu horizonte: 15 anos (longo prazo)

📚 EDUCAÇÃO:
Historicamente, investidores que mantêm posições em quedas 
de 5-10% recuperam em média 6-8 meses.

Vendas por pânico custam, em média, 7% de rentabilidade/ano.

⚠️ IMPORTANTE: Não sou seu consultor. Não posso recomendar 
comprar ou vender. Cada situação é diferente.

Quer conversar com seu consultor sobre isso?
[SIM, AGENDAR] [OK, VOU ESPERAR]"
```

**⚠️ Compliance CVM:**
- NUNCA recomenda ativo específico
- NUNCA diz "compre" ou "venda"
- SEMPRE oferece escalação para consultor humano
- SEMPRE inclui disclaimer
- Apenas educa com dados públicos e históricos
