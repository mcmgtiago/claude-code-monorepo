## 📊 ICP Principal: Empresas de Serviços Financeiros

### Segmentação por Tamanho

#### 🟢 **Micro (1-5 pessoas)**
- Contadores autônomos, consórcio iniciante, assessor independente
- **Problema:** Trabalham sozinhos, perdem leads, sem tempo pra prospecting
- **Solução ARIEL:** Agentes 1, 2, 4 (qualifica, propõe, responde)
- **Preço:** R$ 200-400/mês
- **LTV:** 18-24 meses (churn baixo se bem atenido)

#### 🟡 **Pequeno (6-20 pessoas)**
- Escritório contábil, consórcio pequeno, fintech em crescimento
- **Problema:** Equipe desorganizada, leads esfriando, compliance manual
- **Solução ARIEL:** Todos agentes + dashboard
- **Preço:** R$ 600-1.200/mês
- **LTV:** 36+ meses (defensável, difícil sair)

#### 🔴 **Médio (21-100 pessoas)**
- Escritório contábil consolidado, empresa de investimentos, operadora de consórcio
- **Problema:** Processos cascata, falta automação, retenção de cliente
- **Solução ARIEL:** Plataforma full + customizações
- **Preço:** R$ 2.000-4.000/mês + setup
- **LTV:** 48+ meses (enterprise stickiness)

## 💰 4 Nichos Estratégicos para Financeiro

### 1️⃣ **CONTABILIDADE** (40% do foco)

**Mercado:**
- 400k contadores no Brasil
- Margem: 40-60%
- Ticket médio: R$ 400-1.200/mês

**Pain Points:**
- Leads esfriando (sem follow-up automático)
- Clientes saem sem aviso (compliance não funciona)
- Documentação manual (RPA, NF-e, folha)
- Compliance trabalhoso (prazos, guias)

**Agentes Críticos:**
1. Agent 01 — Qualifica MEI/Simples/Lucro Real
2. Agent 02 — Proposta com preço por regime
3. Agent 04 — Responde "qual prazo?", "quanto custa?"
4. Agent 07 — Processa NF-e, folha, RPA
5. Agent 09 — Alerta DAS, DCTF, E-Social (evita multa)
6. Agent 12 — Agendamento com especialista

**Personas:**
- **Contador Senior** (35-60 anos): organizado, quer crescer, paga bem
- **Escritório Pequeno** (2-10 pessoas): caótico, mas cresce rápido
- **Contador Nômade** (MEI): solo, quer escalar sem contratar

**Go-To-Market:**
- LinkedIn: grupos de contadores + associações
- Direto: ligação + trial de 7 dias
- Referência: "Quanto economiza com ARIEL?" (números)

**Previsão:**
- CAC: R$ 800-1.500
- LTV: R$ 14.400 (3 anos)
- Payback: 3-4 meses

---

### 2️⃣ **CONSÓRCIO** (30% do foco)

**Mercado:**
- 5.000+ operadoras de consórcio no Brasil
- Margem: 30-50%
- Ticket médio: R$ 800-2.000/mês

**Pain Points:**
- Leads não qualificados (chatbot genérico)
- Consórcio é venda consultiva (precisa de proposta customizada)
- Follow-up longo (60-90 dias típico)
- Clientes desistem no meio (falta de acompanhamento)
- Documentação é pesada (3103 RG, CPF, contracheque, comprovante residência)

**Agentes Críticos:**
1. Agent 01 — Qualifica por renda + margem consignável
2. Agent 02 — Simula consórcio (parcelado, taxa, prazo)
3. Agent 04 — Responde dúvida de consórcio
4. Agent 07 — Processa contracheque + RG + CPF (valida renda)
5. Agent 12 — Agendamento com gerente de vendas
6. Agent 06 — Task manager (lembrar cliente de próximo passo)

**Personas:**
- **Gerente de Vendas:** quer fechar mais rápido, quer CRM automático
- **Operador de Consórcio:** crescimento agressivo (5-20% a.m.)
- **Fintech de Crédito:** quer validar cliente de forma automática

**Go-To-Market:**
- LinkedIn: direct outreach para gerentes de venda
- Evento: simulação ao vivo (gera 20+ leads em 1 evento)
- Direto: WhatsApp para gerente + "quanto você perde por mês em follow-up?"

**Previsão:**
- CAC: R$ 1.500-2.500
- LTV: R$ 21.600 (3 anos)
- Payback: 2-3 meses

---

### 3️⃣ **INVESTIMENTOS** (20% do foco)

**Mercado:**
- 50k assessores de investimento (PF + PJ)
- 2k fintechs de investimento
- Margem: 50-80% (consultiva)
- Ticket médio: R$ 1.500-3.000/mês

**Pain Points:**
- Leads precisam de educação (quer saber se vale a pena)
- Simuladores básicos (não personalizam)
- Follow-up é crucial (60% dos leads viram clientes em 3-6 meses)
- Compliance pesada (LGPD + regulação CVM)
- Documentação complexa (KYC — Know Your Customer)

**Agentes Críticos:**
1. Agent 01 — Qualifica por perfil de risco + capital disponível
2. Agent 02 — Gera simulação customizada de investimento
3. Agent 04 — Responda "qual a melhor opção pra mim?" (educação)
4. Agent 07 — Processa documentação KYC
5. Agent 08 — Relatório mensal de performance (retenção)
6. Agent 12 — Agendamento com consultor

**Personas:**
- **Assessor de Investimento:** PJ, crescimento orgânico (R$ 50k-200k/mês de AUM)
- **Startup Fintech:** seed/série A, quer automação pra crescer 10x
- **Banco Digital:** crescimento agressivo, quer onboarding automático

**Go-To-Market:**
- LinkedIn: assessores + fintechs
- Podcast: "Como fechar mais clientes investidor"
- Direto: "Quanto você ganha em AUM? Quanto perde em follow-up?"

**Previsão:**
- CAC: R$ 2.000-3.500
- LTV: R$ 36.000 (3 anos, ticket maior)
- Payback: 2-3 meses
