# LEX (Advocacia)

**AI Operating System para Advogados.**

8 skills para estratégia de caso, geração de peças, controle de prazos e pesquisa jurídica.

Para começar: `/firm-setup`

---

## ✅ O que você consegue fazer

### Análise de Caso

- **`/case-strategy`** — Análise com **8 vetores** (Fato, Prova, Qualificação, Precedente, Processual, Lógico, Pergunta do Juiz, Estratégico). Defect vs Gap. Severity Scale.
- **`/conflict-checker`** — Base de conflitos automática. Red / Yellow / Green.
- **`/precedent-finder`** — STF / STJ súmulas + IRDR + IAC

### Geração de Documentos

- **`/document-generator`** — Petições, contestações, contratos, pareceres
- **`/legal-research`** — Pesquisa estruturada de direito + doutrina

### Operacional

- **`/obligation-tracker`** — Calendário CPC automático + prazos recursais
- **`/firm-setup`** — Onboarding do escritório
- **`/content-creator`** — LinkedIn jurídico
